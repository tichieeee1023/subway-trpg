# 확장 게임 규칙 및 QA 공략

2026-09-18. 개발/QA 문서이며 스포일러가 포함되어 있다. 원본 추가 코드의 오류와 통합 결정을 [검토 기록](expansion-review.md)에 남겼다.

## 프롤로그와 캐릭터 생성

첫 게임 시작은 곧바로 캐릭터 선택으로 넘어가지 않는다. 비 내리는 역사로 막차가 천천히 들어오는 장면 위에서 2장면 프롤로그가 먼저 재생된다. 각 장면은 텍스트를 즉시 완성한 뒤 `> 다음`으로 넘기며, 마지막 장면의 `돌발 퀘스트 시작`을 눌러야 캐릭터 생성 화면이 열린다. `인트로 건너뛰기` 또는 완주 기록은 `subway-opening-seen-v1`에 저장되며, 이후 게임 시작은 곧바로 캐릭터 생성으로 진입한다. 프롤로그는 게임 상태나 주사위 결과를 바꾸지 않는다.

## 컨디션

| D20 | HP / 최대 HP | SAN / 최대 SAN | 특성 |
| --- | --- | --- | --- |
| 1 | 16/16 | 12/15 | 카페인 중독: DEX 보정 -1 |
| 2~7 | 18/18 | 14/15 | 피로 누적 |
| 8~14 | 20/20 | 15/15 | 표준 컨디션 |
| 15~19 | 22/22 | 15/15 | 가벼운 발걸음: DEX 보정 +2 |
| 20 | 20/20 | 15/15 | 잃을 게 없음: SAN 피해 면제 |

HP/SAN 피해는 0 미만으로 떨어지지 않는다. 둘 중 하나가 0이면 결과 이야기를 닫을 때 생존 실패로 종료하며 이후 행동을 허용하지 않는다. SAN 공포 감소는 일반 탐사에서 2~3, 최종전 맨몸 강행은 4이다. 멘톨 캔디는 SAN +3, 드링크/단백질 바는 HP +5, 붕대는 HP +8이며 상한을 넘지 않는다. 회복이 필요하지 않을 때는 소모하지 않는다.

## 탐사

모든 탐사 구역은 AP 3, 선택지 6개이다. 성공/실패와 관계없이 조사에 AP 1을 쓴다. 같은 지점은 재조사할 수 없다. 판정/결과 모달이 열린 동안 다른 행동을 차단한다. 랜턴이 없으면 조사당 배터리를 객차에서 3%, 이후 5% 소모한다. 배터리 잔량은 현재 규칙에서 사망/판정 실패 조건은 아니다.

| 구역 | 조사 ①~⑥ | 핵심 규칙 |
| --- | --- | --- |
| 6호차 | 가방 / 인터폰 / 밸브 / 쇼핑백 / 유리창 / 얼룩 | ④ 스패너 필수. 3회 조사 후 실제 소지품에 스패너가 없으면 BAD 1 |
| 터널 | 대피 홈 / 전화기 / 트로리 / 고압선 / 집수정 / 점검함 | ① INT 11 랜턴, ③ STR 11 빠루, ⑤ 절연장갑, ⑥ STR 10 소화기 |
| 승강장 | 노선도 / 자판기 / 거울 / 안내센터 / 점막 / 점검문 | ① 판정 성공·③·④는 위화감 발견. ⑤ 산성액은 장갑이 없으면 HP -2. 조사 후 3번 출구/직원 통로 선택 |
| 상가 | 편의점 / 마네킹 / CCTV / 개찰구 / 약국 / 덕트 | ① 카드키/드링크, ② DEX 11 멀티툴, ③ INT 12 CCTV, ⑤ 붕대. 카드키가 있으면 ④ 판정 생략 |

위화감 0에서 3번 출구로 향하면 BAD 2. 위화감이 있으면 출구 함정을 알아채고 직원 통로로 우회한다. 직원 통로는 위화감과 무관하게 안전하다. 터널 고압선 실패는 HP -6, 절연장갑을 가지고 있으면 -2이다. 같은 ID의 아이템은 중복 보관하지 않고, 보관 수 제한으로 새 도구를 버리지 않는다.

## 최종전

| 단계 | 행동 | 판정 / 소모 |
| --- | --- | --- |
| 1 배기팬 | 스패너 → 멀티툴 → 산성액 우선순위의 도구 정공법 | 보유 도구 필요, 확정 성공, 1턴. 산성액만 소모하며 장갑 없으면 HP -2 |
| 1 배기팬 | INT / STR / DEX | DC 12 / 11 / 14, 1턴. CCTV는 INT DC를 9로 낮춤. STR에는 빠루/노트북 가방/텀블러/소화기 필요 |
| 1 실패 | INT / STR / DEX | HP -5 / -6 / -8. INT는 장갑이 있으면 -2. 단계 1에 머무름 |
| 2 촉수 | 랜턴 / 소화기 | 실제 보유 필수, 확정 성공, **0턴**. 소화기 통은 타격에 다시 사용 |
| 2 촉수 | 커터칼 | 실제 보유, DEX DC 10, 1턴. 실패 시 HP -6/SAN -3, 단계 3으로 진행 |
| 2 촉수 | 맨몸 | HP -7/SAN -4, 1턴, 단계 3으로 진행 |
| 3 맨홀 | 빠루 + 스패너/텀블러/소화기 | 두 도구 보유 필요, 확정 탈출, 1턴 |
| 3 맨홀 | STR | 빠루 보유 시 DC 9, 없으면 DC 14. 1턴. 실패 HP -3 |

비탈출 행동으로 턴이 0이 되면 BAD 3이다. 마지막 1턴의 맨홀 개방 성공은 탈출이 우선되어 생존 엔딩을 판정한다. 잘못된 단계 호출이나 미보유 도구는 턴을 소모하지 않는다.

## 엔딩 및 도감

엔딩을 하나 이상 완료한 뒤 도감을 열 수 있다. 첫 엔딩 전에는 인트로·헤더 도감 버튼이 잠긴다. 개발 서버의 인트로/캐릭터 선택 화면에서 **Ctrl+Shift+F10**을 누르면 6종을 모두 수집하고 도감을 연다. 재시작/새로고침 후에도 기록이 유지되며, 프로덕션 빌드에서는 이 개발 키가 동작하지 않는다.

| ID | 조건 |
| --- | --- |
| BAD_1 | 스패너 없이 객차 조사 종료, 또는 객차에서 HP/SAN 붕괴 |
| BAD_2 | 위화감 없이 가짜 출구 선택, 또는 승강장에서 HP/SAN 붕괴 |
| BAD_3 | 최종전 시간 소진/탈출 실패, 그 외 구역의 HP/SAN 붕괴 |
| TRUE | 탈출 성공 후 HP >= 12 **그리고** SAN >= 8 |
| GOOD | TRUE 미달, HP >= 10 **그리고** SAN >= 7 |
| NORMAL | 두 수치가 모두 양수인 나머지 탈출 성공 (HP 9 이하 또는 SAN 6 이하) |

도감은 `subway_0037_endings`의 문자열 ID 배열을 읽는다. JSON 오류/배열 아닌 값/알 수 없는 ID/중복은 무시한다. 재시작은 게임 진행만 초기화하며 도감·설정은 유지한다. 브라우저 저장이 차단되어도 현재 세션에서는 수집할 수 있다. 모든 6개 ID를 획득해야 격리 작전의 진상과 미확인 수질 관측 기록이 담긴 후일담을 열 수 있다. 미발견 카드는 이미지/이름을 숨긴다.

## TRUE 추천 경로

1. 엔지니어 선택/확정 → 컨디션 굴리기.
2. 객차 ④ 쇼핑백 → ③ 밸브 → ⑥ 얼룩. 스패너를 반드시 확보.
3. 터널 ① 대피 홈 → ③ 트로리 → ⑤ 집수정. 랜턴/빠루 판정 성공 필요.
4. 승강장 ① 노선도 → ④ 안내센터 → ⑥ 점검문 → 직원 통로.
5. 상가 ① 편의점 → ③ CCTV → ⑤ 약국. 필요하면 소지품의 회복 버튼 사용.
6. 도구 정공법(1턴) → 랜턴(0턴) → 빠루+스패너(1턴). 최종전 자체 피해 없이 탈출.

주사위 실패는 추천 경로 성공을 보장하지 않는다. 랜턴 실패 시 터널 ⑥ 소화기를 대안으로 택하고, 빠루 실패 시 맨홀 STR 판정을 해야 한다.

## 검증 실행

`npm.cmd test`, `npm.cmd run lint`, `npm.cmd run build`를 실행한다. 기본 dist 잠금이 있으면 `npm.cmd run build -- --outDir dist-review`로 별도 산출물을 검사한다.

브라우저 검사는 Vite를 4173 포트로 실행한 뒤 `node tools/verify-game-browser.mjs`를 사용한다. 실제 Chrome 버튼 입력으로 6종 엔딩, 수집/후일담/저장 유지, 캐릭터 확인, 9개 화면의 선택지, 주사위 이미지·캔버스·고정 높이, 글씨 확대/효과 제거, 잘못된 저장값을 검사한다. `node tools/verify-expanded-accessibility.mjs`는 글씨 확대와 효과 제거 상태에서 모든 탐사/승강장 경로/최종전 단계의 선택지와 HUD를 320×568, 375×667, 844×390 화면에서 추가 검사한다. 테스트용 난수를 고정하며 실제 게임 확률을 바꾸지 않는다. 결과 캡처는 `artifacts/game-review/`에 저장한다.
